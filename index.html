Tentang

Full-stack, dari database sampai layar.

Saya mulai sebagai Full-Stack Developer pada 2021 dengan Laravel, Bootstrap, jQuery, dan MySQL. Lama-lama saya makin sering kebagian bagian yang berat: laporan ringkasan yang lambat, import dan export data besar, serta modul ERP yang saling terhubung. Saya juga sempat membuat aplikasi mobile dengan Flutter.

Sejak 2025 sebagian besar waktu saya ada di sebuah platform keuangan berskala besar: dari versi Laravel sampai versi barunya yang berbasis microservice Go dan Nuxt, termasuk engine import, workflow, laporan, dan asisten AI-nya. Di sela itu ada proyek lain: backend API, admin panel, boilerplate Go, dan integrasi Kafka. Di luar kode, saya biasa membuat flowchart, memimpin modul, dan berdiskusi langsung dengan klien.

  • Komunikasi. Menerjemahkan kebutuhan klien jadi flowchart, lalu jadi fitur.
  • Memimpin. Memegang modul ERP dan memberi arahan teknis ke tim.
  • Problem-solving. Membongkar bug dan query lambat sampai ketemu penyebabnya.
